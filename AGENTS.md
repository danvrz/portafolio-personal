# Convenciones del portafolio de Daniel Vertiz

- Stack: React, Vite, JavaScript y CSS. Mantener una aplicación estática sin backend.
- Usar npm y conservar package-lock.json. No instalar herramientas globales.
- Contenido y documentación en español. Nombres de componentes en PascalCase.
- Componentes reutilizables en src/components; vistas en src/pages; datos en src/data.
- Mantener los proyectos en src/data/projects.js. Cada slug debe ser único.
- No inventar credenciales, experiencia, resultados ni datos de contacto.
- Marcar proyectos de demostración y sus ilustraciones de forma explícita.
- Conservar navegación por teclado, foco visible, HTML semántico, diseño responsive y preferencia de movimiento reducido.
- Paleta: #FAFAF7, #202C2B, #246B63 y #C9DFD6.
- Añadir comentarios solo para explicar decisiones o comportamientos poco evidentes.
- Antes de entregar cambios funcionales ejecutar npm run build y probar las rutas afectadas.
- No publicar, crear repositorios remotos, realizar commits ni avanzar a GitHub sin que Daniel apruebe el diseño inicial.
- Pedir autorización antes de acciones destructivas, instalaciones globales o modificaciones fuera del proyecto.
